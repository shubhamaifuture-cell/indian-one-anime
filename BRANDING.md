# 🎌 DUBKAMI - Branding Guidelines

## Logo & Identity

### Official Name
- **Website**: इंडियन वन एनीमे (Indian One Anime)
- **Mobile App**: DUBKAMI
- **Combined Brand**: DUBKAMI - Indian One Anime

### Logo Description
The official logo features:
- 🦁 **Golden Lion Head** - Symbol of strength and power
- ⭐ **8 Golden Stars** - Representing excellence
- 🇮🇳 **Indian Flag** - National pride and identity
- 🟡 **Golden Circle Border** - Professional and premium feel
- 🟥 **Maroon Background** - Rich and warm color

### Color Palette
| Color | Hex Code | Usage |

| Gold | #FFD700 | Logo accents, text |

### Typography
- **Primary Font**: Bold, Modern Sans-serif
- **Secondary Font**: Regular Sans-serif
- **Logo Text**: DUBKAMI (uppercase)

## Usage Guidelines

### ✅ Do's
- Use the complete logo with text
- Maintain proper spacing around logo
- Use on both light and dark backgrounds
- Keep aspect ratio consistent
- Use official color palette

### ❌ Don'ts
- Don't modify logo colors
- Don't distort or rotate logo
- Don't add additional elements
- Don't use low-quality versions
- Don't change proportions
